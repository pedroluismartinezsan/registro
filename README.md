# Registro Ciudadano – Equipo Pedro León

Aplicación PWA instalable que abre el registro ciudadano de Google Apps Script.

- **Repositorio:** https://github.com/pedroluismartinezsan/registro
- **Dirección cuando GitHub Pages esté activado:** https://pedroluismartinezsan.github.io/registro/
- **Apps Script:** https://script.google.com/macros/s/AKfycbwbJ_jkgUYPEYpqH-zJoIjbURtBPwIMTq-eHb9itSd41afWHvP_dWlxAJZkJXNSEEUZ-g/exec

## Activar GitHub Pages
1. Abre **Settings > Pages** del repositorio.
2. Selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
3. Abre la dirección de la PWA en Chrome (Android) o Safari (iPhone).

## Instalar
- **Android:** menú de Chrome > «Instalar aplicación» o «Añadir a pantalla de inicio».
- **iPhone:** Safari > Compartir > «Añadir a pantalla de inicio».

## Precauciones
La PWA abre Apps Script mediante iframe. Si Apps Script bloquea la inserción, utiliza **Abrir en navegador**. No modifiques por este motivo la seguridad del servidor sin revisar el riesgo de clickjacking. El registro, las modificaciones y las eliminaciones requieren conexión. Los datos de Google Sheets y la contraseña de administrador no están publicados en este repositorio. La URL de la fotografía alojada en Facebook puede vencer.

No se ha verificado todavía la instalación ni el funcionamiento desde Android/iPhone.
